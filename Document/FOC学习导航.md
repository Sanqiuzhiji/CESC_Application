# CESC FOC 学习导航

这组文档不是通用 FOC 教程，而是本工程的“地图”。建议一边阅读，一边在 IDE 中跳转到文中列出的函数。

## 先看哪些文件

1. [硬件平台导读](FOC硬件平台导读.md)：认识控制器、三相逆变桥、电流/母线采样、编码器及定时器同步关系。
2. [软件代码导读](FOC软件代码导读.md)：沿着启动、慢速任务、20 kHz 电流环中断读代码，并把 Clarke/Park、PI、反 Park 和 PWM 串起来。
3. `Application/MotorControl/README.md`：现有模块职责概要。
4. `Document/Schematic_Prints.pdf`：原理图原件；硬件修改必须以它和实际 PCB/BOM 为最终依据。
5. `CESC_PROTOCOL_V1.md`：上位机命令、诊断量和参数辨识接口。

## 工程里的 FOC 一句话地图

```text
USB命令 -> 外环(10 ms) -> Id/Iq目标
                           |
AS5600(2 ms) -> 电角度/PLL  |
                           v
TIM1 PWM -> TIM8延时触发三ADC -> 20 kHz ADC中断
                                  |
                    偏置校正/相电流重构
                                  |
                    Clarke + Park -> Id/Iq
                                  |
                    d/q PI + 限幅 -> Vd/Vq
                                  |
                    反Park -> Valpha/Vbeta
                                  |
                    SPWM或SVM -> TIM1 CCR1/2/3
```

## 建议的学习节奏

- 第 1 阶段：不接电机，只理解 `.ioc`、引脚、PWM 频率、死区和保护信号。
- 第 2 阶段：保持栅极关闭，观察 1024 点电流零偏校准与母线电压换算。
- 第 3 阶段：给 `foc.c` 的纯数学函数写主机侧测试，验证角度、符号和饱和行为。
- 第 4 阶段：限流电源、空载电机，依次完成编码器检查、电角度对齐、低能量旋转。
- 第 5 阶段：理解电流环，再学习速度环、位置环、轨迹和观测器。

## 必须先知道的工程现状

- MCU 为 STM32F405RGT6，系统时钟 168 MHz。
- TIM1 为中心对齐三相互补 PWM，ARR=4199，对应 20 kHz PWM；死区寄存器值为 84。
- 三路 ADC 在 PWM 零矢量后约 1.19 us 同步采样，ADC1 完成中断承担快速控制环。
- 角度传感器为 AS5600，I2C2 以 400 kHz 通信，任务每 2 ms 轮询一次。
- 默认电机为 11 对极，最大命令 Iq 为 300 mA，母线有效范围为 6~15 V。
- 当前采样换算约为 80.6 mA/count，分辨率较粗；软件因此保留了直接 Vq 控制路径。
- 默认 `speed_current_foc_enabled=0`、`high_speed_svm_enabled=0`。也就是说 FOC 电流环和 SVM 已有实现，但默认速度运行路径并不等同于“全速度范围电流 FOC + SVM”。阅读和实验时务必区分“代码具备”与“配置启用”。

## 安全边界

这是功率电子工程。不要在不了解母线电压、MOSFET 额定值、DRV8301 配置、电流采样极性和电机参数时直接使能桥臂。首次实验使用限流电源、低母线电压、空载电机和急停手段；示波器测半桥时使用合适的差分探头或隔离方案，禁止用接地夹直接短接开关节点。
