# Application code

This directory contains code owned by the application rather than generated by
STM32CubeMX.

## Modules

- `application`: application lifecycle and the boundary used by generated code.
- `vesc_protocol`: USB byte buffering, VESC frame parsing, and command dispatch.
- `vesc_crc`: protocol CRC-16 calculation.
- `firmware_update`: staging Flash operations and bootloader handoff.

Keep `Core` and `USB_DEVICE` changes limited to STM32CubeMX `USER CODE` blocks.
New product behavior should normally be implemented here and exposed through a
small function in `application.h` when generated code needs to call it.
